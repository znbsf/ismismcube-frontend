# 全分类树立场研究：340 个格位的首轮内容覆盖

本目录按原库的 **4 个一级、16 个二级、64 个三级、256 个四级格位，共 340 个节点**写成立场阅读材料。每个节点有课程格位证据、普通读者可读的画像与主要矛盾、同级判别、最强反方及公平回应、内在张力、自我辨认问题和有界的正反原典记录。**340 指内容和结构覆盖，不表示 340 个格位已由原典双向证实，也不表示日常发言已能精确归码。**原库定义、UI、旧试点冻结判读均未改动。

阅读一篇真实发言时，先把作者自己的前提、理由、例证和结论连起来，再给可能的上位或四位候选，逐格说明原话支持、推断和缺口。随后用同父邻格的转向条件、最强反方和原典局部论证检查定位。资料不足可以给出有用的立场重构与张力点评，精确课程码保持待定；不能把发言中的问题、条件假设或引用他人话语自动算作作者承诺。

## 原典缺口与解释边界

下表按 **`pro_sources` / `con_sources` 是否为空**计数，是与各节点明示局部命题相匹配的一手文本记录缺口；非空不证明四维全格，空缺也不是反证。

| 阶段 | 节点 | 正方数组空 | 反方数组空 | 两侧皆空 |
| --- | ---: | ---: | ---: | ---: |
| A | 20 | 2 | 0 | 0 |
| B | 64 | 2 | 0 | 0 |
| C1 | 128 | 8 | 13 | 1 |
| C2 | 128 | 12 | 12 | 3 |
| 合计 | **340** | **24** | **25** | **4** |

A 的 `1-3`、`1-4` 原典正方数组恢复为空；施蒂纳段只在 `comparison_sources` 作相邻或相反机制的边界对照。另有五个 Sol 节点的旧“正方”段落只谈邻近主题、文学表达或作者描述，已同样移作边界对照，不能计正方。B 的 `4-1-3`、`4-3-4` 虽有同原典的条件检验，仍缺**独立外部反方**，不在数组空缺数内。Sol 另有 7 个同文内部检验节点，Terra 也标出若干同源条件检验；这些数组虽非空，仍不等于历史上双方直接论战。四级 `4-4` 的 16 格全是课程未来数字共同体设定，均缺支持**完整虚构体系**的历史正面原典；非空正方数组只记录身份、体验、具身或新开始等局部比较。相应限制可在各条 `supports` / `limits` 查看。最强反方是编者公平重构。主控最后将 `3-3-4-2` 的司法判决移至 `comparison_sources`：它是现实制度反例，不能替代哲学著作，因此反方哲学原典缺口另计。

### 阶段 D 查补及尚未完成的核读

本轮对原有空数组逐条检索并查补相符的**局部**原典，又剔除了话题近似的正方误挂。空数组从上一轮的正方 79、反方 135 变为 24、25。Sol 原有 102 个空侧中，86 个补入有界原典、9 个经具体候选作品和段落核对后继续留空、7 个改列边界对照并恢复正方缺口；[逐项审计](stage-d-sol-audit.json)记录候选、定位与不匹配原因，[同源复核](stage-d-sol-weak-source-review.json)记录重复引用的处理。Terra 对仍空的 27 个节点补做按作者、实际论题与作品的定向检索，并在 `evidence_status.stage_d_claim_search` 写出候选与失败原因；`4-3-1-4` 的拟议写入遭自动审批拒绝，单独记录。有些候选全文不可读或只见摘要，**不能称已经核读相应原典**。双方审查见 [Sol 复核](review-sol-D.md)、[Terra 复核](review-terra-D.md)。本阶段仍有正反原典空缺；当前交付是可审阅的研究状态，不是所有 340 格的双向原典完成证明。

## 全文试读教会我们的规则

A 至 C2 共记录 **16 篇主要完整发言分析，另有 B 的 1 篇约197词短篇完整补充**；A 的两篇曾在旧长段试验出现，不计为新独立样本。来源是公开日常帖或讨论，按同一作者完整论证的首尾锚点和所读范围界定，不把评论或他人发言并入。C2 的 Sol 两篇低于英文500词优先长度，但保留全文边界；Terra 两篇约583、795词。它们不是盲测、没有金标，也不能计算准确率。

- **机制和目的要同在。** C1 曾把“反复”误联到诗性循环、把普通职业选择误联到萨特；C2 曾把团队分歧误作赫拉克利特的活火生成、把对莱布尼茨完美论的反问误写成正例。交叉审查撤回这些词语误配，重写合成例和候选条件。
- **主要矛盾先写立场要解决的问题。** B 与 C2 多处初稿其实是外部反方质问；修后将这些质问移到反方或内在张力，把问题自身的两端说清。
- **原典只证明自己说过的局部命题。** 孔德学科等级不能证明生存机制，已换达尔文关于生存斗争与有利可遗传变异的原段；奎因的整体检验和实用修订不等于某项实践效益已实现。饶勒斯的反战原文起点与同页丹东段已分清。因找不到贴合段落而保留的空数组，不靠万能休谟或马克思段落充数。

所有日常教学例句均标 `synthetic`；画像说的是**采用此立场时可能如何思考和行动**，不是对发言者的固定人格、心理状态或隐秘动机的判断。固定讲稿 URL 与原库轴文用于课程定位，本批未把所有讲稿原音逐段核对。真实发言中的技术和政策事实也未因用于立场分析而获得独立验证。

## 校验

运行 `python research/classification-pilot/tree-expansion/validate-a.py`、`validate-b.py`、`validate-c1.py`、`validate-c2.py` 与 `validate-tree.py` 可检查各级编号、父子、名称、原库原句、来源字段、局部链接和 340 项唯一覆盖。机器不能判断原典的哲学适用性、译文准确度或立场判读是否成立。B/C1/C2 阅读版分别由 [render-b.py](render-b.py)、[render-c1.py](render-c1.py)、[render-c2.py](render-c2.py) 从冻结 JSON 生成。
