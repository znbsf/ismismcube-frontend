# 分类说明试点：先看论证，再看编号

**现行入口：立场分析与辩证点评。**先读[使用方法](STANCE-ANALYSIS.md)，再按[14类立场阅读与4-2教学扩展](CATEGORIES.md)理解各立场的关心、主要矛盾、四维、最强反方、内在张力和自我辨认问题。[完整发言示范](STANCE-EXAMPLES.md)分析数字永生整帖、工会组织整帖及课程4-2示例。旧三轮输入、初判和长短配对仍作为证据历史，不再把完整课程码命中当主要产出；定位是有条件的坐标，不是人格判定或准确率。

这组材料为“主义主义”课程的 15 个节点试写可判别的通俗解释，其中**首批原典局部对读验收 14 类，另有 4-4 一类保留为对照附录**。它沿用现有分类，不修改原库定义，也不把课程编号当作学界公认谱系或人的身份标签。八个第 1、2 字头节点由 Sol 整理，七个第 3、4 字头节点由 Terra 整理；双方交叉审查对方的类别及真实文本候选。

## 怎么用

1. 先读待判断的一段论证，写下它实际上谈了什么；不要先用“进化”“康德”“实践”等单词锁定编号。
2. 在 [CATEGORIES.md](CATEGORIES.md) 查看相邻节点的四维通俗解释、两条合成正例、近似反例及区分问题。短编号只规定已有格位；其余记为未知，不补齐。
3. 对每个已规定的格位分别标“段落直接支持／合理推断／未知／反证”，再给最多几个候选或弃判。两条合成正例是局部判别探针，不保证单独证明四格。
4. 把课程格位依据与原典依据分开。课程链接指向固定社区讲稿转录，未核原音；原典链接只证明已核读的局部命题，不能代替课程的四维定义或整部哲学著作。

## 这次实际检验到哪里

[EVALUATION.md](EVALUATION.md) 汇集双向交叉判读：Sol 对 Terra 的 7 条固定书面摘录，Terra 对 Sol 的 10 条固定书面摘录。它们来自公开原著或作者论文，保留了实际输入、中文自译/释义、候选、逐格已知/未知和相邻边界；多数摘录很短，出现有意的弃判或仅到父节点。T4、T6、T7 的来源上下文与固定输入已分列，不能借上下文替短句作证。过程是开放资料对读，双方可查看来源和分类草稿，**不是盲测，也不提供准确率**。没有可靠逐字稿的真实日常口头发言输入，因此不能声称已验证日常话语分类效果。

**第二轮真实日常文字检验**见 [round-02/REPORT.md](round-02/REPORT.md)：V2EX 中文帖子/评论八条、Reddit 英文论坛文字八条，双方先独立判读再互审。16 条均为公开网络书面发言，仍无口语逐字稿；只有局部线索、近似边界或弃判，没有完整四格命中，也没有金标准确率。十类判别提示已依据真实输入的证据缺口补充，原判和修订前后均保留。首批仍为14类，4-4仍是对照附录。

**第三轮有理由的日常书面发言检验**见 [round-03/REPORT.md](round-03/REPORT.md)：另取 V2EX 八条中文、Reddit 八条英文公开论坛原文，固定输入与双方先冻结的独立判读在该目录。T03/T04 的组织与成员反馈、T05 的住房建设、T01/T08 的劳动分配批评可记录有证据的局部倾向；对完整课程四格仍须弃判。两组各四类判别提示按真实 case_id 修订，见 [round-03/CHANGES.md](round-03/CHANGES.md)。没有口语逐字稿、盲测、独立金标或准确率；4-4 仍只作附录。

第三轮集中复核另发现 S02 一处证据状态标注错误：未出现功能主义心理因果角色只能记为未知，不能记为反证。独立初判保留原样，阅读结论以 [adjudication.json](round-03/adjudication.json) 的复核状态为准；功能主义的核心机制证据也不能单独补齐课程四格。

**第四轮与阶段收口**见 [round-04/REPORT.md](round-04/REPORT.md) 和 [STAGE-SUMMARY.md](STAGE-SUMMARY.md)。又有16条新公开论坛书面发言，完成双向独立判读及互审；本轮没有可确认误归码或缺证误记反证。三轮共48条去重发言（中文29、英文19），仍无完整四格命中、独立金标或口语逐字稿。阶段总结合并14类覆盖与缺口，并示范三条有理由的局部判读。4-4始终只作对照附录；本阶段不再开新轮。

用户随后要求比较完整论证与短摘录。[四篇长段配对报告](long-passages/REPORT.md)在既有帖子中固定两篇中文、两篇英文的连续论述，阅读全文后交叉判读。其中 LS01 最初的563字中段截去作者的核心结论；复核已把[中文详细示范](long-passages/EXAMPLE-REPORT.md)的主输入扩至楼主行19–117全文，旧短摘录与旧563字判读原样留作历史对照。全文明确给出跨载体、功能接管与延续意识目标，功能主义成为有证据的局部机制候选，但仍不赋完整课程码。四篇均与旧样本配对，不增加48条独立发言计数；未产生足以修改既有分类规则的证据。

## 文件与证据边界

- [STANCE-ANALYSIS.md](STANCE-ANALYSIS.md)：从完整论证到定位、矛盾、反方与有条件点评的方法；[STANCE-EXAMPLES.md](STANCE-EXAMPLES.md)：数字永生与工会两篇全文分析，以及课程4-2教学示例；[STANCE-REVIEW.md](STANCE-REVIEW.md)：本轮双向互审与具体修正。
- [CATEGORIES.md](CATEGORIES.md)：首批14类与1类对照附录的连续阅读版。[sol-categories.json](sol-categories.json) 与 [terra-categories.json](terra-categories.json)：结构化类别、四维与出处。
- [EVALUATION.md](EVALUATION.md)：17 条固定文本交叉判读。[sol-evaluation.json](sol-evaluation.json) 与 [terra-evaluation.json](terra-evaluation.json)：逐条结构化记录。
- [sol-notes.md](sol-notes.md) 与 [terra-notes.md](terra-notes.md)：选材理由、真实原文输入和风险。[sol-review.md](sol-review.md) 与 [terra-review.md](terra-review.md)：双方审查与修订记录。
- [round-02/REPORT.md](round-02/REPORT.md)、[round-02/CHANGES.md](round-02/CHANGES.md)：真实论坛文字的覆盖矩阵、双向判读、无金标边界及 before/after 修订。该目录四份 JSON 保留冻结输入和初判。
- [round-03/REPORT.md](round-03/REPORT.md)、[round-03/CHANGES.md](round-03/CHANGES.md)：第三轮16条新论坛输入、独立判读、互审、14类覆盖矩阵与修订前后。原始输入及初判保留于本轮四份 JSON。
- [round-04/REPORT.md](round-04/REPORT.md)、[round-04/CHANGES.md](round-04/CHANGES.md)：最终轮16条新论坛输入、双向判读、互审与八类判别文字修订。[STAGE-SUMMARY.md](STAGE-SUMMARY.md) 汇总三轮样本、14类覆盖及边界。
- [long-passages/REPORT.md](long-passages/REPORT.md)、[long-passages/EXAMPLE-REPORT.md](long-passages/EXAMPLE-REPORT.md)：四篇既有公开帖的长短配对阅读，来源边界、四维交叉初判与 LS01 完整正文的扩展示范；[扩展来源](long-passages/sol-source-expanded.json)、[Terra 扩展独立判读](long-passages/terra-evaluation-expanded.json)及[扩展互审](long-passages/sol-review-expanded.md)保留复核链。

原典支持有明显边界：图灵论文不足以证明功能主义的多重实现，因此 Sol 另核普特南本人论文；达尔文的自然选择不支持课程中的预定上升阶梯；笛卡尔第二沉思局部不等于完整心物二元证明；贝克莱的精神不能当被动理念；休谟的习惯论不直接证明课程伦理格。Terra 所引莫尔《乌托邦》是 4-4 的比较近反例，不能正面证明课程特定的未来共同体、爱欲或技术设定；3-2 另以费希特原典局部补足自我设定对照。版本、译者与核读范围以各条记录为准。
