# 从这里开始读主义主义

这份入口帮助你读懂课程编号，并把课程解释与原典对照起来。说明依据社区整理的 `weathour/ismism-system` 分讲稿，固定版本为 `b4d66c15e3d0e4361f6c6b58821e39dd7e947fb2`。本次核读的是下列局部文字，没有核听原音；Page 是各分讲文件自己的页标签，L 是 Markdown 行号。未取得总纲视频的已核正文，因此不把下面的简表当成讲者完整、最终的定义。

## 先认位置，再看数字

四位编号按顺序表示**场域论—本体论—认识论—目的论**。短编号只写到相应层级：`1` 是第一层，`1-1` 细分到第二层，`1-1-4-4` 才具体到第四层。讲者在1-3复习课把四格解释为相互贯穿的结构，并以背景与前景关系说明其嵌套；不是四个互不相干的标签。[1-3复习课，Page 1–3，L9–15](https://github.com/weathour/ismism-system/blob/b4d66c15e3d0e4361f6c6b58821e39dd7e947fb2/corpus/clean-markdown/1_%E5%AE%9E%E5%9C%A8%E8%AE%BA/1-3_%E5%BA%B8%E4%BF%97%E5%94%AF%E6%88%91%E8%AE%BA_%E5%A4%8D%E4%B9%A0%E8%AF%BE/0046_1-3_%E5%BA%B8%E4%BF%97%E5%94%AF%E6%88%91%E8%AE%BA_%E5%A4%8D%E4%B9%A0%E8%AF%BE_p1069.md#L9-L15)

| 位置 | 初读时可以追问什么 |
| --- | --- |
| 第一位：场域论 | 这个立场预设怎样的整体背景、秩序或关系？ |
| 第二位：本体论 | 在这个背景中，什么被认作存在，存在怎样组织、显现？ |
| 第三位：认识论 | 现象、感知和认识依靠什么前提或中介？ |
| 第四位：目的论 | 整个体系朝什么方向运作，这如何表现为行动准则与伦理姿态？ |

这些问题是便于阅读的转述。原文把前两格近似称为实体侧、后两格称为主体侧，随即否认把二者僵硬切开；目的论也不只是个人职业目标，而涉及整个体系的运行方向。[同讲，Page 1–3，L9–15](https://github.com/weathour/ismism-system/blob/b4d66c15e3d0e4361f6c6b58821e39dd7e947fb2/corpus/clean-markdown/1_%E5%AE%9E%E5%9C%A8%E8%AE%BA/1-3_%E5%BA%B8%E4%BF%97%E5%94%AF%E6%88%91%E8%AE%BA_%E5%A4%8D%E4%B9%A0%E8%AF%BE/0046_1-3_%E5%BA%B8%E4%BF%97%E5%94%AF%E6%88%91%E8%AE%BA_%E5%A4%8D%E4%B9%A0%E8%AF%BE_p1069.md#L9-L15) [社会行为主义，Page 7，L27](https://github.com/weathour/ismism-system/blob/b4d66c15e3d0e4361f6c6b58821e39dd7e947fb2/corpus/clean-markdown/1_%E5%AE%9E%E5%9C%A8%E8%AE%BA/1-1_%E5%A4%8D%E4%B9%A0%E8%AF%BE/1-1-4_%E8%A1%8C%E4%B8%BA%E4%B8%BB%E4%B9%89/1-1-4-4_%E7%A4%BE%E4%BC%9A%E8%A1%8C%E4%B8%BA%E4%B8%BB%E4%B9%89/0023_1-1-4-4_%E7%A4%BE%E4%BC%9A%E8%A1%8C%E4%B8%BA%E4%B8%BB%E4%B9%89_p515.md#L27)

## 为什么它不能直接替代哲学史

课程会重排问题的进入顺序。观念论总论先讲现象学，再讲德国古典观念论，理由是讲者认为前者帮助澄清后者；这本身就是解释方案，不能按课程编号倒推出历史年代或公认学派谱系。[观念论总论，Page 1，L9](https://github.com/weathour/ismism-system/blob/b4d66c15e3d0e4361f6c6b58821e39dd7e947fb2/corpus/clean-markdown/3_%E8%A7%82%E5%BF%B5%E8%AE%BA_%E4%BD%9C%E4%B8%BA%E4%B8%80%E4%B8%AA%E7%8E%B0%E4%BB%A3%E4%BA%BA_%E8%AF%A5%E6%80%8E%E6%A0%B7%E6%80%9D%E8%80%83%E5%93%B2%E5%AD%A6/0187_3_%E8%A7%82%E5%BF%B5%E8%AE%BA_%E4%BD%9C%E4%B8%BA%E4%B8%80%E4%B8%AA%E7%8E%B0%E4%BB%A3%E4%BA%BA_%E8%AF%A5%E6%80%8E%E6%A0%B7%E6%80%9D%E8%80%83%E5%93%B2%E5%AD%A6_p4951.md#L9)

因此，读“某哲学家属于某格位”时，要拆开三件事：课程为何这样安排；所引原典实际论证了什么；编者提供的对照能支持哪一部分。相同书名或学派名称不保证概念用法相同。讲者自己也批评把一个编号认领为身份、贯彻生活所有环节而停止思考的做法。适合练习的是解释一段论证，不是给自己或别人盖章。[庸俗主义，Page 22–23，L118–121](https://github.com/weathour/ismism-system/blob/b4d66c15e3d0e4361f6c6b58821e39dd7e947fb2/corpus/clean-markdown/1_%E5%AE%9E%E5%9C%A8%E8%AE%BA/1-4_%E5%A4%8D%E4%B9%A0/1-4-4_%E5%BA%B8%E4%BF%97%E4%B8%BB%E4%B9%89_%E4%BA%BA%E4%B8%BA%E4%BB%80%E4%B9%88%E4%BC%9A%E5%8F%98%E5%BE%97%E5%BA%B8%E4%BF%97_%E5%8F%98%E5%BE%97%E6%AF%94%E5%B9%B3%E5%BA%B8%E6%9B%B4%E5%B9%B3%E5%BA%B8_%E5%AE%B6%E9%87%8C%E6%9C%89%E5%A8%83%E7%9A%84%E5%BF%85%E7%9C%8B/0091_1-4-4_%E5%BA%B8%E4%BF%97%E4%B8%BB%E4%B9%89_%E4%BA%BA%E4%B8%BA%E4%BB%80%E4%B9%88%E4%BC%9A%E5%8F%98%E5%BE%97%E5%BA%B8%E4%BF%97_%E5%8F%98%E5%BE%97%E6%AF%94%E5%B9%B3%E5%BA%B8%E6%9B%B4%E5%B9%B3%E5%BA%B8_%E5%AE%B6%E9%87%8C%E6%9C%89%E5%A8%83%E7%9A%84%E5%BF%85%E7%9C%8B_p2224.md#L118-L121)

## 一条可以执行的阅读路线

**第一步，练习拆格。** 先读上面的1、2总论局部和1-3复习课Page 1–3，再看[社会行为主义条目](READING-GUIDE.md#1144)。回到该讲Page 4–7，分别找出其世界背景、物质设定、心灵解释和目的方向。随后读条目关联的米德《心灵、自我与社会》第18节：只比较自我与有机体的区别，暂不要求一次判断整套分类。[社会行为主义，Page 4–7，L18–27](https://github.com/weathour/ismism-system/blob/b4d66c15e3d0e4361f6c6b58821e39dd7e947fb2/corpus/clean-markdown/1_%E5%AE%9E%E5%9C%A8%E8%AE%BA/1-1_%E5%A4%8D%E4%B9%A0%E8%AF%BE/1-1-4_%E8%A1%8C%E4%B8%BA%E4%B8%BB%E4%B9%89/1-1-4-4_%E7%A4%BE%E4%BC%9A%E8%A1%8C%E4%B8%BA%E4%B8%BB%E4%B9%89/0023_1-1-4-4_%E7%A4%BE%E4%BC%9A%E8%A1%8C%E4%B8%BA%E4%B8%BB%E4%B9%89_p515.md#L18-L27)

**第二步，练习原典对照。** 从[笛卡尔条目](READING-GUIDE.md#2324)的《第二沉思》第3–4段开始，写下怀疑中保留下来的确定性；再读[休谟条目](READING-GUIDE.md#2414)所列观念关系、事实推断与习惯段落。各写一句“原文论证”和一句“课程解释”，让两句能够分别回查。这里的书目关系是编者关联，不自动等于原课明确推荐。

**第三步，进入观念论。** 先读3总论Page 1–2提出的有限体验与普遍有效性问题，再依[康德条目](READING-GUIDE.md#3211)读第二版序言及导论VII，区分先验问题、现象与物自身。之后进入[黑格尔逻辑学条目](READING-GUIDE.md#3241)，从纯有、纯无、变易及扬弃的局部开始。此处先做小范围比较，不把网页节选当成已经读完体系。[观念论总论，Page 1–2，L9–14](https://github.com/weathour/ismism-system/blob/b4d66c15e3d0e4361f6c6b58821e39dd7e947fb2/corpus/clean-markdown/3_%E8%A7%82%E5%BF%B5%E8%AE%BA_%E4%BD%9C%E4%B8%BA%E4%B8%80%E4%B8%AA%E7%8E%B0%E4%BB%A3%E4%BA%BA_%E8%AF%A5%E6%80%8E%E6%A0%B7%E6%80%9D%E8%80%83%E5%93%B2%E5%AD%A6/0187_3_%E8%A7%82%E5%BF%B5%E8%AE%BA_%E4%BD%9C%E4%B8%BA%E4%B8%80%E4%B8%AA%E7%8E%B0%E4%BB%A3%E4%BA%BA_%E8%AF%A5%E6%80%8E%E6%A0%B7%E6%80%9D%E8%80%83%E5%93%B2%E5%AD%A6_p4951.md#L9-L14)

**第四步，读实践及其内部差异。** 回到4总论Page 1–4，观察它为何修改中介的理解；接着读[实践条目](READING-GUIDE.md#4)关联的《关于费尔巴哈的提纲》第一、二、三、八、十一条，再到[经济学哲学批判](READING-GUIDE.md#4111)，比较《1844年经济学哲学手稿》的异化劳动与《资本论》商品章。最后进入4-3、4-4：前者讨论建设，后者明确以不可能乌托邦作思想实验。不要将VR、AI意识等设定读成已实现技术。[不可能的乌托邦，Page 1–3，L9–15](https://github.com/weathour/ismism-system/blob/b4d66c15e3d0e4361f6c6b58821e39dd7e947fb2/corpus/clean-markdown/4_%E5%AE%9E%E8%B7%B5/4-4_%E4%B8%8D%E5%8F%AF%E8%83%BD%E7%9A%84%E4%B9%8C%E6%89%98%E9%82%A6/0342_4-4_%E4%B8%8D%E5%8F%AF%E8%83%BD%E7%9A%84%E4%B9%8C%E6%89%98%E9%82%A6_p8560.md#L9-L15)

## 继续读正文与原典

[READING-GUIDE.md](READING-GUIDE.md)按编号汇集摘要、轴说明、局部来源与待核问题；[BIBLIOGRAPHY.md](BIBLIOGRAPHY.md)按书目反查条目、版本和核读范围；[COVERAGE.md](COVERAGE.md)说明正文入口及研究覆盖。字段已有文字、已有课程入口、已据局部复核、已核原音是不同状态，不能相互替代。

`$`系列另见[30讲正文导读](COURSE-READINGS.md)。从纯有、纯无、变易一路到本质、现实性和概念，摘要按ASR逐讲整理，并链接黑格尔《逻辑学》的相应章节。课程自创名称、解释性比喻和原典章节标题分开；30讲是本次找到的范围，不表示系列已经完结。原站人工摘要的逐字段发现可在[校对覆盖表](MANUAL-REVIEW.md)回查。

每读完一讲，留下四项即可：编号、用自己的话写出的论点、支持它的局部出处、尚未解决的问题。遇到“课程明确提及”与“编者关联”，保留标签；遇到转录疑点，先核相邻段落与原音，再决定是否改字或改解释。
