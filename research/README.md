这些文件是二手编纂文本，可能包含OCR、转录及编辑错误。Page指每个文件内部的页标签，行号指固定版本Markdown行号，不能当作出版物页码。文件首尾可能跨讲；摘要记录了实际使用的段落，4-4-4-3使用下一讲回顾补录的位置也单独说明。文件下载、哈希通过与全文审阅是不同状态。

视频目录交叉使用 [ismism-map](https://github.com/MAK1MA-AG0NY/ismism-map/blob/c37c8df2e328560cad4321cdcefdc21aa2bc6374/README.md) 与 [meridian-archive](https://github.com/shibusama/meridian-archive/tree/e82394824940b9504721a9a2a6a71039e1f6646a)。完整402条目录保存于 [public/courses.json](../public/courses.json)，编号—讲稿关系保存于 [public/transcripts.json](../public/transcripts.json)。

- 两处原待核目的论已经按明确正文处理，旧的“仅据收束段归纳”不再是当前结论。4-4-4-4另有板书支持；其他图式、公式中仅凭转录无法确定的细节仍保留疑点。
- 原有42条AI摘要核对的是99组核心论断，不能把人工摘要1544字段的完成状态外推到它们。
- 典籍关联按具体问题扩展，未覆盖所有编号；版本、译者及实际阅读范围据可见页面记录，未伪造中文版本页码，未声称通读所有书。
- 本次定位的30讲`$`正文已整理；未找到正文的其他番外、预习、复习版本不因目录存在而被标为读完。搜索未发现后续讲次不能证明没有后续。
- 原站340条“原视频”入口含337个BV链接及3个金山文档入口，未宣称全部视频可播放。

4-4分支的VR、AI意识、死亡与再生内容按讲者的思想实验整理，不作为科学技术事实。课程对哲学家的归类、心理推测和政治判断，与作者原著立场、历史事实分别标注。查到讲稿确实如此说时，保留课程转述，另附原典差异；不把讲者与原典的差异一律归咎于AI摘要。

## 复现与维护

```powershell
python scripts/build-research.py
python scripts/check-research.py --source-cache ../source-cache/weathour
```

没有本地讲稿缓存时可省略 `--source-cache`，仍能检查引用、字段完整性、修改日志回放及生成文件一致性。`check-research.py`还运行15项合成验证场景，覆盖标题冒充内容证据、缺失引用与定位、轴越界、无课程证据的典籍提及、字段漂移、不连续修改链、课程正文身份、正文定位与原音状态冲突。它不判断哲学论证真假。

`build-research.py`只验证并生成研究索引，不自行覆盖主数据。应用已审阅批次须显式指定：

```powershell
python scripts/apply-reviewed-research.py --batches 文件名.json
python scripts/apply-reviewed-research.py --batches 文件名.json --write
```

第一条预览，第二条写入并记录精确前后值。应用时保留来源、AI标记和未决状态。前端源码与依赖未改，因此本轮未运行前端构建，也未启动后台服务。后续证据工作见 [计划与未决范围](PLAN.md)。
