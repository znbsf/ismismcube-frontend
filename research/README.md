## 验证与复现

[修改日志](applied-changes.json)的1360个字段变更步骤，已从原始Git提交完整回放至当前数据。[validation.json](validation.json)记录24项合成验证、13份生成文件一致性、430份缓存身份及本地音轨/转录/板书哈希检查。机器检查不能证明哲学论证或转录语义正确。

```powershell
python scripts/build-research.py
python scripts/check-research.py --source-cache ../source-cache/weathour
```

没有本地缓存时省略`--source-cache`，仍可检查结构、引用、覆盖、修改日志和生成一致性。检查还会拒绝旧人工/AI字段覆盖退步、补充课程缺正文记录、标题充当正文证据、未知引用、字段漂移、不连续修订和重复运行失效。部分板书记录仍按部分状态计数，不被“有记录”改成“全文完成”。

应用已审阅批次须显式指定，先预览，再写入：

```powershell
python scripts/apply-reviewed-research.py --batches 文件名.json
python scripts/apply-reviewed-research.py --batches 文件名.json --write
```

前端源码与依赖未改，本轮没有运行前端构建或部署；本地转录使用隔离环境，两次进程均已完成退出，没有遗留转录服务。
